# 02 - Entrada e Saída de Dados

A entrada e saída de dados permite que o programa receba informações do usuário e apresente resultados na tela.

## 📚 Resumo

**Entrada de dados:** é o processo de receber informações fornecidas pelo usuário durante a execução do programa. Em Java, podemos utilizar a classe `Scanner` para realizar essa entrada.

**Saída de dados:** é utilizada para apresentar informações, mensagens e resultados na tela. Em Java, utilizamos principalmente `System.out.println()` e `System.out.print()`.

**Scanner:** permite capturar diferentes tipos de dados digitados pelo usuário, como números inteiros, números decimais e textos.

Exemplos:

- `nextInt()` → recebe números inteiros.
- `nextDouble()` → recebe números decimais.
- `nextLine()` → recebe textos.
- `next()` → recebe uma palavra.

## 🎯 Objetivo

Aprender a receber informações do usuário e utilizar esses dados para realizar operações e apresentar resultados em Java.
