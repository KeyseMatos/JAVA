# 11 - Projetos

Esta pasta é destinada aos projetos desenvolvidos durante os estudos de programação, utilizando na prática os conceitos aprendidos nos conteúdos anteriores.

## 📚 Resumo

Os projetos têm como objetivo aplicar os conhecimentos de Java e Programação Orientada a Objetos na construção de programas completos.

Durante os projetos, os conteúdos estudados podem ser utilizados de forma integrada, como:

- Variáveis e tipos de dados
- Estruturas condicionais
- Estruturas de repetição
- Vetores
- Métodos
- Classes e objetos
- Encapsulamento
- Herança
- Polimorfismo

Cada projeto será organizado de acordo com sua finalidade e poderá conter diferentes classes e arquivos necessários para seu funcionamento.

## 🎯 Objetivo

Praticar os conhecimentos adquiridos durante os estudos de Java, desenvolver a lógica de programação e aprender a construir projetos aplicando os conceitos de forma integrada.
