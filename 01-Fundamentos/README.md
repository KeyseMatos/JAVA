# 01 - Fundamentos de Java

Os fundamentos de Java são a base para compreender a linguagem e desenvolver programas. 
Nesta etapa, são estudados conceitos como variáveis, tipos de dados, operadores, entrada 
e saída de informações e estruturas básicas de programação.

## 📚 Resumo

**Variáveis:** são utilizadas para armazenar informações durante a execução do programa, 
como números, textos e valores lógicos.

**Tipos de dados:** definem o tipo de informação que uma variável pode armazenar. 
Os principais são `int`, `double`, `float`, `char`, `boolean` e `String`.

**Operadores:** permitem realizar cálculos e comparações. Podem ser aritméticos, 
relacionais e lógicos.

**Entrada e saída de dados:** permitem que o programa receba informações do usuário 
e apresente resultados. Em Java, o `Scanner` é utilizado para receber dados pelo teclado, 
enquanto `System.out.println()` exibe informações na tela.

**Lógica de programação:** consiste em organizar instruções e condições para que o 
programa execute uma determinada tarefa.

## 🎯 Objetivo

Desenvolver uma base de lógica de programação e compreender os principais conceitos 
iniciais da linguagem Java.
