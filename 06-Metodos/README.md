# 05 - Vetores

Os vetores são estruturas utilizadas para armazenar vários valores do mesmo tipo dentro de uma única variável. Cada valor armazenado possui uma posição, chamada de índice.

## 📚 Resumo

**Declaração de um vetor:** em Java, um vetor pode ser criado definindo o tipo dos dados e a quantidade de posições que ele terá.

Exemplo:

```java
int[] numeros = new int[5];
