# 04 - Repetição

As estruturas de repetição permitem executar um determinado bloco de código várias vezes, evitando a necessidade de escrever as mesmas instruções repetidamente.

## 📚 Resumo

**Laço `for`:** utilizado principalmente quando sabemos ou conseguimos determinar a quantidade de vezes que uma ação deverá ser repetida.

A estrutura do `for` possui três partes principais:

```java
for (inicialização; condição; incremento) {
    // código que será repetido
}
